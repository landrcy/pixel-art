# pixel-art

Pixel art and tools by Finley.

- `sea-sprites/` sprites for the Sea of Thought site (gulls, pirate ships, sea creatures) with `manifest.json` and a preview sheet
- `dungeon-icons/` dungeon icon art
- `manuscript-border/` manuscript border art for the hub intro
- `hub-logo-and-scene/` hub logo and intro scene art
- `tools/` pixel art helper script, playbook and demo
